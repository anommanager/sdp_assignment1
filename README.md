# Assignment 1

An example of using the builder pattern.

Project files:

- App.java - the main entry point for demonstration the builder pattern.
- CarBuilder.java - the interface for building car parts.
- Car.java - An immutable class representing a car object with brand, model, and price properties.
- CarModelBuilder.java - implements the builder interface to create a json string representation.
- CarObjectBuilder.java - implements the builder interface to create a json string representation.
- CarDirector.java: orchestrates the construction process.

How to run:
````
```
./gradlew run
```
